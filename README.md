Healthcare Cost Calculator

Project Overview

An AI/ML-based application that predicts annual health insurance charges using personal information.

Input Features

- Age
- BMI
- Smoking Status
- Region

Technologies

- Python
- NumPy
- Pandas
- Scikit-learn
- Matplotlib
- Streamlit
